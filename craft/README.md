# Craft

Deep, measured guidance on the decisions that actually determine whether an interface looks
designed. Load the one the current decision needs — these are long and you should not read them all.

| Question | File |
|---|---|
| What typeface, what sizes, what weights, what numerals? | [`typography.md`](typography.md) |
| What colours, how many, light and dark? | [`color.md`](color.md) |
| How much space, what widths, what grid, what rhythm? | [`space-and-layout.md`](space-and-layout.md) |
| How dense should this be? Where does hierarchy come from? | [`density-and-hierarchy.md`](density-and-hierarchy.md) |
| Hover, focus, loading, optimistic updates, undo, destructive actions | [`interaction-and-states.md`](interaction-and-states.md) |
| Should this animate, how much, how long? | [`motion-craft.md`](motion-craft.md) |
| Forms, inputs, validation, settings pages | [`forms-craft.md`](forms-craft.md) |
| Tables, dashboards, charts | [`tables-dashboards-data.md`](tables-dashboards-data.md) |
| Navigation, IA, sidebars, search as navigation | [`navigation-and-ia.md`](navigation-and-ia.md) |
| Button labels, errors, empty states, tone | [`copy-and-voice.md`](copy-and-voice.md) |
| Breakpoints, mobile, touch, safe areas | [`responsive-and-mobile-web.md`](responsive-and-mobile-web.md) |

Each file opens with **"if you only apply five things"** and closes with a **self-check** you can
run against your own output. If you are short on context, read those two sections and skip the
middle.

Every measured value was read from a live product. Where a file could not measure something it says
so rather than guessing.
