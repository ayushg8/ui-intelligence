# Visual reference, teardown and inspiration resources

**Evaluated:** 2026-09 · **Researcher note:** The category split in two and then consolidated. One half (Mobbin, Refero, Nicelydone, Page Flows, ScreensDesign, Built for Mars) turned into paid, searchable archives of *real shipped product screens* and every one of them shipped an MCP server in the last cycle — an agent can now query proven UI instead of guessing. The other half (Awwwards, Dribbble, FWA, Behance, Savee, Cosmos) is still an aesthetics feed and has drifted further from product work, not closer. Meanwhile four names on most people's list are gone: UI Sources, Design Vault, Scrnshts and Screenlane all 301 into competitors, and Typewolf hasn't posted since Dec 2025.

## Recommendations by need
- **Default choice:** **Mobbin** — the live library counter reads **1,428 apps · 621,500+ screens · 323,900 flows** (2026-09-09), and the MCP means an agent can pull "43 paywalls from shipped products" instead of inventing one.
- **Best value / best for an agent on a budget:** **Refero** — $10/mo gets 142,000+ screens, user flows, MCP, Figma plugin *and* a published agent skill. Cheapest path from "build me a settings page" to a real precedent.
- **Best for web/B2B SaaS specifically:** **Nicelydone** — 202,400+ web-app screens with full-text search *inside* the screenshots, and it shows what's behind paywalls and trials.
- **Best for interaction and transitions:** **Page Flows** — recordings, not stills. The only way to see what happens *between* two screens.
- **Best reasoning (not just pictures):** **Built for Mars** — 90+ case studies and 1,400+ examples that argue a position instead of showing a screenshot.
- **Best engineering reference:** **The Component Gallery** — cross-references 60 components against 95 real design systems, so you name and structure things the way mature teams do.
- **Best specification reference:** **Checklist Design** — 129 checklists of what a paywall, data table or empty state must actually contain. Free, and it ships as an agent skill.
- **Best for interaction *detail*:** **Design Spells** — 332 credited micro-interactions from real shipped apps. The antidote to generic motion.
- **Best on why users behave that way:** **Growth.Design** alongside Built for Mars — 53 free case studies that argue from psychology rather than taste.
- **Best negative reference:** **Deceptive Patterns** — the named taxonomy of manipulations. Check your flow against it before you ship it.
- **Best for typography:** **Fonts In Use** for the archive, **SiteInspire** for how type behaves in layout.
- **Lightest / free and current:** **Sidebar** — five links a weekday, no account, no paywall.
- **Premium/paid worth it:** Mobbin ($10/mo) and Refero ($10/mo) both clear the bar easily. ScreensDesign at $299/yr only if you ship iOS subscription apps.
- **Actively avoid for product work:** Dribbble, Awwwards, Behance, FWA, Uiverse.

## Scorecards

### Mobbin — `essential`
- **What:** A searchable library of real product screens, flows and animations from shipped iOS, Android and web apps, plus an MCP server for AI agents.
- **Verdict:** This is the reference the whole category is measured against, and it earned it by indexing what companies actually shipped rather than what designers posted. The 2026 move that matters is the MCP: an agent asked for a paywall can retrieve dozens of real ones and synthesize, which is a categorically different input than a text prompt. The free tier is deliberately crippled — no flows, no animations, no search, three collections — so treat this as a $10/mo dependency or not at all. Its own marketing site is the cleanest thing in the category and tells you something about the people running it.
- **Use when:** you need precedent for a specific product surface — onboarding, paywall, empty state, settings, filters. · **Don't use when:** you want art direction or a visual mood; it will give you competent, conventional product UI and nothing more.
- **Scores /5:** visual 5 · interaction 4 · a11y 3 · engineering 5 · maintenance 5 · docs 4 · customization 3 · perf 4 · stability 5 · originality 4
- **Evidence (re-verified 2026-09-09):** live library counter reads **1,428 apps · 621,500+ screens · 323,900 flows** — the "600,000+ screens" figure on mobbin.com/mcp and the "over 1,000 iOS & Web apps" hero line are both *behind* the counter, so quote the counter · Pro $10/member/mo billed yearly, Team $16/member/mo, Finance+ add-on $399/mo · free tier: limited apps, max 3 collections, no Flows/Animations/Search/MCP · claims 2M+ designers and a logo wall of Shopify, Nike, Pinterest, Duolingo, Wise (their claim, not independently verified) · Mobbin MCP launch reported as 2026-05-11 by third-party write-ups, **not stated first-party** — unverified
- **Looked at:** https://mobbin.com — logged-out marketing page at 1440. Tight grotesk set at ~120px with negative tracking, pure white ground, one black pill CTA and one outlined ghost CTA, no shadow, no gradient, no card radius theatrics. A greyscale logo wall at 40% opacity. Restraint held for a full viewport, which almost nothing else in this category manages. Note the *library* UI is behind login and was not inspectable.
- **Vibecode risk:** low, with one honest caveat. It will not give you the Dribbble look. It will give you the *median* look: 1,428 real products averaged out is still an average. It immunises against gradient-glow slop and does nothing about sameness. Pair it with Design Spells or a real art direction source when the brief needs a point of view.
- **Link:** https://mobbin.com

Smaller library than Mobbin and no Android. The free tier is ~3% of the collection, which is enough to evaluate and not enough to use.
- **Use when:** you want the cheapest agent-queryable path to real product precedent, or you work inside Figma. · **Don't use when:** you need Android, or you need the deepest possible app coverage — Mobbin still wins on volume.

Mobbin's centre of gravity is consumer mobile; Nicelydone is B2B web software, which is what most people reading this are actually building. Two features do real work: full-text search *inside* screenshots (find every product that used the word "seat" on a billing page) and screens captured from behind paywalls and trials, which is where the interesting UI lives and where public screenshots never reach. The one real risk is structural — it appears to be a single operator (support goes to a personal address), so treat it as a subscription that could stop.

### Built for Mars — `strong`
- **What:** Peter Ramsey's library of long-form UX case studies pulling apart the real onboarding, checkout and retention flows of named companies, plus short "UX Bites" examples.
- **Verdict:** Every other entry here shows you *what* someone shipped. This one argues about *why* it works or doesn't, with the tradeoff named. That's the input that stops an agent from copying a pattern into a context where it's wrong. It has commercialized — bootcamp, pathways, quizzes, a paywall — and the free archive is thinner than it was, but £8/mo is trivial and it now ships an MCP and a Figma plugin, so the reasoning is reachable from inside a build loop. Its positioning is unusually honest about the moment: "A collection of UX research, examples and 'ohhh that makes sense' moments for people who care about design, in a sea of AI slop."
- **Use when:** you're making a judgment call — how many onboarding steps, whether to gate before or after value, how to word a cancellation. · **Don't use when:** you need visual reference; the case studies are annotated screenshots, not a gallery.
- **Scores /5:** visual 4 · interaction 3 · a11y 3 · engineering 3 · maintenance 5 · docs 4 · customization 2 · perf 4 · stability 4 · originality 5
- **Evidence:** "90+ UX Case Studies & 1,400+ UX Examples" (page title) · BFM+ Individual £8/mo billed annually; Teams £32/mo for 5 seats (£6.40/person); students/educators discounted · MCP access, Figma plugin and monthly AI credits listed in the plan comparison · registered as Built for Mars Ltd, England & Wales, Co. No. 12731987
- **Looked at:** https://builtformars.com at 1440 — heavy geometric-sans headline at ~64px, near-black on white, one black CTA, and hand-drawn marker annotations on yellow highlighter over the product shot below the fold. It commits to a voice instead of a template, which in a category full of identical dark-hero SaaS pages is itself a recommendation.
- **Vibecode risk:** low.

### The Component Gallery — `strong`
- **What:** A free reference that indexes 60 interface components against 95 real design systems, with 2,671 concrete examples and links to each system's docs.
- **Verdict:** The most useful thing on this list that has nothing to do with inspiration. Before you build a "Tree view" or a "Combobox", this tells you what mature teams call it, what it's expected to do, and how ten different systems structured its API. That kills two failure modes in agent-built UI at once: inventing a name nobody uses, and inventing an anatomy that doesn't match anyone's mental model. Free, no account, fast, and its own page design is the best-executed in this entire research set.
- **Use when:** naming, scoping or specifying a component before implementation. · **Don't use when:** you want visual inspiration — the examples are structural references, not eye candy.
- **Scores /5:** visual 5 · interaction 4 · a11y 5 · engineering 5 · maintenance 4 · docs 5 · customization 4 · perf 5 · stability 4 · originality 5
- **Evidence:** "60 components, 95 design systems, 2,671 examples" stated on the homepage (2026-09) · free, no signup · built on Astro (data-astro attributes in markup) · ⌘K search and a light/dark toggle
- **Looked at:** https://component.gallery at 1440 — warm off-white ground with a faint engineering graph-paper grid, a high-contrast Didone-ish display serif at ~110px for the counts, hairline 1px rules forming a genuine visible grid, and pale-blue isometric line-art glyphs for each component. No shadows used as decoration, no gradient CTA, no rounded-card default. This is a designer who knows what a grid is for. Would survive a portfolio review.
- **Vibecode risk:** low — pushes you toward standard component semantics, which is the opposite of vibecoding.
- **Link:** https://component.gallery

### Checklist Design — `strong` *(added 2026-09 challenge pass)*
- **What:** 129 free checklists of what a given screen or flow must actually contain — Paywall, Data Table, Empty State, Admin Panel, Audit Log, Multi-step form, Canceling subscription — grouped as Mobile app / Web app / Website / Design system / Flows. Ships as an agent skill, a Figma skill and a Figma plugin.
- **Verdict:** The clearest omission from the last pass, and it sits exactly on the corpus's own thesis. Component Gallery tells you what to *call* a thing and how mature teams structure it; Checklist Design tells you what the thing must *contain* before it is finished. Those are different failure modes and this covers the second one. An agent asked for a billing page will produce something plausible and leave out the invoice history, the tax ID field, the failed-payment state and the seat proration copy — this is the list that catches that. ### Growth.Design — `strong` *(added 2026-09 challenge pass)*
- **What:** Dan Benoni and Louis-Xavier Lavallée's library of UX case studies delivered as illustrated comics, each pulling apart one real product's flow through a named psychological principle, plus a Principles library and paid masterclasses.
- **Verdict:** The last pass named Built for Mars "best reasoning (not just pictures)" and then failed to mention its closest peer, which is a straightforward gap rather than a judgment call. The two are complementary, not redundant: Built for Mars measures and argues from the flow outward; Growth.Design argues from the psychology inward and names the effect — labor perception bias, scarcity, the aha moment — so the reasoning transfers to a surface it never studied. That is the property you want when an agent has to make a judgment call in a context no case study covers. The comic format is slower to read than it looks and the free tier is real: 53 case studies, no paywall on the archive.
- **Use when:** you need to justify or challenge a flow decision on something other than taste, and want the underlying principle named. · **Don't use when:** you need visual or component reference — there is none. Also don't use it as evidence: it argues persuasively and rarely shows the counterfactual.
- **Scores /5:** visual 4 · interaction 3 · a11y 3 · engineering 2 · maintenance 4 · docs 3 · customization 1 · perf 4 · stability 4 · originality 5
- **Evidence (2026-09-09):** page title "53 UX Case Studies To Improve Your Product Skills" · case studies tagged Ethics / Onboarding / Retention / Revenue / Referral / Premium / Psychology, each with a read time (2–5 min) and a named company (Strava, Audible, McDonald's, Grammarly, Apple) · "Join 132,793 people" (their claim) · free archive plus paid masterclasses · **no MCP and no agent skill** — unlike Built for Mars, it is not reachable from a build loop
- **Looked at:** rendered the live index and the case-study directory. Clean, warm, illustration-led; the comic panels are the content, so there is nothing to screenshot that summarises it.
- **Vibecode risk:** low.
- **Link:** https://growth.design

### Deceptive Patterns — `reference-only` *(added 2026-09 challenge pass)*
- **What:** Harry Brignull's taxonomy of manipulative interface patterns (formerly darkpatterns.org) — named types, a hall of shame, the relevant laws and live enforcement actions.
- **Verdict:** The only *negative* reference in the category and the file was poorer for missing it. Every other entry answers "what do good products do here"; this one answers "what will get you sued, and what is the name for the thing you just built by accident". That second half matters more than it sounds for agent-built UI: confirmshaming, comparison prevention, hard-to-cancel and nagging are all patterns an agent will produce innocently while optimising a funnel, because the training data is full of them and they demonstrably convert. Having the named taxonomy in the corpus means the failure is nameable at review time instead of shipping. It has also grown teeth — it now tracks enforcement, so this is compliance reference, not just ethics reading. Filed reference-only because you check work against it rather than draw from it.
- **Use when:** reviewing any flow that involves cancellation, consent, pricing, subscription or a funnel target. · **Don't use when:** you want design reference of any kind — it is prose and annotated examples.
- **Scores /5:** visual 3 · interaction 2 · a11y 4 · engineering 2 · maintenance 4 · docs 5 · customization 1 · perf 4 · stability 5 · originality 5
- **Evidence (2026-09-09):** nav is Types / Hall of shame / Laws / Enforcement / Reading list / Books / About · named types include Addictive Design, Comparison Prevention, Confirmshaming, Currency Confusion, and the rest of the standard taxonomy · self-describes as "spreading awareness since 2010" and now covers AI systems explicitly ("features of apps, websites **and AI systems**") · free, no paywall, no signup

What *was* re-verified 2026-09-09: the Winning Websites grid is wall-to-wall studio and agency SOTD entries (Studio Freight, Locomotive, Resn, Merci Michel, basement studio, Unseen Studio, SHIFTBRAIN, Vide Infra), and the last pass's read of the visual content holds — a WebGL magenta-gradient hero, a 3D stealth-aircraft render over rock, a full-bleed ocean photograph with display-serif overlay, and a truck flying out of a shipping container. Not one card in the visible grid contained a form, a table, a list, an empty state or a settings screen. These are award submissions optimized for a jury looking at a 20-second scroll — award-bait motion, unbuildable scroll-jacking, no real states, no data density, no accessibility budget. Its genuinely useful part is the Font and Colour filters for palette and type research. Everything else will make your product worse. Also runs two persistent promo layers over the grid.
- **The FWA** — Awwwards' older sibling with the same failure mode and an even heavier bias toward experiential and campaign work. Nothing here has a second session.
- **Dribbble** — Verified live: the current Popular feed is dominated by logo-presentation boards (MolGen, FIELD AI, Ascentra/Nomadic/CoPack), a pencil sketch, and two UI mockups floating inside device frames with invented data — plus a "20% off design services" promo bar and a paid Framer ad slot inside the grid. It is a hiring marketplace whose ranking signal is likes on a static JPEG, which selects for what photographs well in a 400px thumbnail: oversized radii, heavy drop shadows, gradient CTAs, impossible dashboards. Nothing on it was ever built, so nothing on it has an error state, a loading state, a long string, or a real dataset. An agent that learns from Dribbble produces exactly the look people mean by "vibecoded".
- **Behance** — Same disease, larger scale, plus multi-slide case-study theatre where a real screen is one image among twenty mood shots. Adobe-owned, still maintained, still the wrong input.
- **Uiverse** — A community gallery of decorative CSS components: glowing buttons, animated gradient borders, neumorphic cards, hover effects with three-colour shadows. It is a catalogue of the exact tells that mark AI-generated UI. Copying from it is the fastest way to make a product look cheap. It also hard-blocks headless browsers outright ("Sorry, you have been blocked" — Cloudflare), so an agent can't read it even if it should, which it shouldn't. Library size unverified.
- **Collect UI** — Re-indexes Dribbble shots into categories (Sign Up, Dashboard, Checkout, 404 Page, Onboarding). The taxonomy is genuinely useful and the underlying content is Dribbble, so it launders bad reference into a plausible-looking pattern library. That combination makes it worse than Dribbble, not better.
- **Layers.to** — A thin Dribbble-style shot feed. Loads, has a jobs rail, and offers nothing you cannot get better elsewhere.
- **Curated.design** — Live but adds nothing distinguishable from a dozen identical galleries. No reason to spend an agent's attention on it.
- **Lapa Ninja** — Returns 403 to scripted access; landing-page gallery heavily entangled with template sales. Skip in favour of SaaS Landing Page or Land-book.
- **Interfaces.pro** — Serves an anti-adblock detection/redirect script instead of any content. Do not send anyone here.
- **Mobile Patterns** (mobile-patterns.com) — **Correction to the last pass:** the domain *does* resolve (Cloudflare, 104.21.6.26 / 172.67.154.152) and the connection succeeds; it serves HTTP 404 on `/` and on `www`. Still dead as a product, but "does not resolve" was wrong and would have failed a spot-check. Remove it from any list you maintain.
- **Pttrns** — Technically alive and now "completely free", but the navigation is Blog / Technologies / Troubleshoot / How To / Canva. It has been repurposed into an SEO content property with a design gallery attached. Historic value only.
- **UI Sources, Design Vault, Scrnshts, Screenlane** — All four are gone as independent products. uisources.com, designvault.io and scrnshts.club 301 to screensdesign.com; screenlane.com 301s to pageflows.com. If a list still recommends these, the list is stale.

## What surprised me

- **Every serious product-reference site shipped an MCP server, and they did it in the same cycle.** Mobbin (600k+ screens), Refero, Nicelydone, ScreensDesign, Savee (6M+ refs) and Built for Mars all expose their libraries to agents now. The correct 2026 answer to "where should an agent get design reference" is no longer "a website" — it is a $10/mo MCP connection. Savee even publishes its full tool surface and gates writes behind explicit consent. This is the single biggest change in the category and most published lists haven't noticed.
- **Four sites people still recommend do not exist any more.** uisources.com, designvault.io and scrnshts.club all 301 to ScreensDesign; screenlane.com 301s to Page Flows. The mobile-UI-reference segment quietly consolidated into two owners.
- **Typewolf has stopped.** Last Site of the Day is 14 Dec 2025 — nine months of silence, with a three-month gap before that. It is still the most-cited web typography resource in the world and it is now an archive. Fonts In Use has quietly become the live one.
- **Godly renamed itself to recent.design and started a design-agent-skills directory** with public install counts (anthropics/canvas-design at 161.4K, vercel-labs/web-design-guidelines at 29.1K). An inspiration gallery is now indirectly distributing agent tooling — and it's the most useful part of the site.
- **The best-designed thing in this entire research set is a free, unmonetized component reference.** The Component Gallery — off-white ground, real graph-paper grid, Didone display serif, hairline rules, isometric line-art glyphs, no shadows used as decoration — outclasses every VC-funded product in the category on pure craft. 60 components, 95 design systems, 2,671 examples, no signup.
- **Cosmos ships an AI-content detector with Show/Blur/Hide.** A moodboard tool treating "was this generated" as a first-class filter is a sharper read on 2026 than anything the award sites are doing.
- **The best-curated galleries are the ones with no engagement metrics.** SiteInspire shows a name and a relative date and nothing else — no likes, no view counts, no author badges. Dribbble sorts by likes. That single design decision explains most of the quality gap between them.

## Open questions

- **Mobbin's and Page Flows' actual library UI** is behind a paywall; I judged both from public marketing surfaces and taxonomy only. Settling it needs a paid account and a screenshot of the logged-in search results.
- **Whether the MCP servers return image data or only metadata** varies and matters enormously for agent usefulness. Savee documents `view_saves` for fetching actual images; Mobbin, Refero and Nicelydone do not state this publicly. A live MCP connection would settle it in one call each.
- **Cosmos pricing** — the pricing page returns "Sorry, you can't access this" to automated access. Unverified.
- **Land-book and Uiverse corpus quality** — both hard-block headless browsers, so their libraries were not inspected. A human session would settle it.
- **Httpster's current cadence** — the tag taxonomy is live and large but /2025/ and /2026/ both 404. Unverified whether it's still curating or coasting on an archive.
- **Page Flows' library size** — the widely-repeated "2,000+ user flows" figure appears on their pricing page only inside a customer testimonial, not as a first-party claim. Unverified.
- **Nicelydone's bus factor** — support routes to one named individual and the site has run since 2016. Whether there's a team behind it is unverified, and it's the main risk in depending on it.
